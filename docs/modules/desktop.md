# Electron 桌面客户端

桌面客户端是用户操作入口，负责后端连接设置、会话与模型选择、对话展示、工具进度和取消操作。当前在 Mac 上开发和验证，Windows 构建与跨设备实测尚待完成。

## 核心类与入口

| 核心符号或入口 | 职责与源码 |
| --- | --- |
| `BackendClient` | 封装后端 HTTP 请求与事件流、认证和响应校验；见 [backend-client.ts](../../src/desktop/backend-client.ts) |
| `ConnectionSettings` | 读写客户端唯一持久化的后端连接设置，通过注入的加密能力保护令牌；见 [settings.ts](../../src/desktop/settings.ts) |
| `DesktopBridge` | 定义隔离界面可调用的受限能力，由 [preload.ts](../../src/desktop/preload.ts) 接驳主进程；契约见 [bridge.ts](../../src/desktop/bridge.ts) |
| 主进程入口 | 管理窗口、连接和事件订阅，组装设置保存与界面接驳；见 [main.ts](../../src/desktop/main.ts) |
| 界面入口 | 管理设置对话框、对话展示和内存中的交互状态；见 [renderer.ts](../../src/desktop/renderer.ts) |

## 相关模块

| 模块 | 为什么相关 |
| --- | --- |
| [后端服务](backend.md) | 提供模型列表、会话、任务执行和已保存结果，客户端不直接调用模型或工具 |
| `api` | 共享网络契约，约束双方交换的数据 |
| Electron 桌面接驳 | 主进程承担网络、认证和连接设置保存，通过受限接口向界面提供能力 |

首次启动通过独立对话框配置后端，验证连接后才进入主界面。之后使用已保存设置自动连接，失败时返回设置；更换后端后重新获取对应业务数据，旧连接的延迟响应不得覆盖新界面。

前端唯一持久化的数据是后端连接设置，访问令牌受系统加密保护。会话、消息、模型配置、执行状态、记忆及其他业务数据全部由后端保存，界面所需临时状态只驻留内存。

关闭客户端或断线不等于取消后端任务；取消需要明确操作，结果以后端状态为准。桌面与后端可以独立运行，不通过共享本地数据库耦合。

源码入口：[src/desktop/main.ts](../../src/desktop/main.ts)。界面、网络接驳、设置保存与安全隔离的具体实现查阅 [桌面源码目录](../../src/desktop)；验证见 [客户端测试](../../test/desktop) 和 [桌面端到端测试](../../test/e2e)。启动与测试命令统一见 [项目说明](../../README.md#开发命令)。
